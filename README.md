# 🎹 Неон Пиано — Cloud Edition (Firebase + Web Audio API)

Отрефакторенная версия оригинальной ритм-игры **«Неон Пиано»** на модульном **JavaScript (ES6+)**, **HTML5** и **CSS3** с полной привязкой к облаку **Firebase (Firestore + Cloud Storage)**, клиентским шифрованием (Web Crypto API) и звуковым движком без задержек (**Web Audio API**).

---

## 🌟 Ключевые особенности обновленной версии

1. **Исключительно облачная библиотека треков (Cloud-Only)**:
   - Вся музыка и метаданные подтягиваются **строго из облака** (Firestore коллекция `tracks` + Firebase Cloud Storage).
   - Никаких захардкоженных или потерянных локальных файлов: на старте база чистая. При входе в игру меню отображает статус загрузки и стильное сообщение, если треков в облаке еще нет.
   - Любой трек, загруженный администратором, сразу появляется в меню у всех игроков!

2. **Скрытая панель Администратора**:
   - Кнопка «👑 Адмінка» в правом верхнем углу отображается **только** авторизованному администратору.
   - Форма загрузки:
     - Поддержка аудиоформатов `.ogg`, `.mp3`, `.mp4` (аудиодорожки).
     - **Автоматический замер длительности трека** через `AudioContext.decodeAudioData` при выборе файла в браузере.
     - Загрузка файла в **Firebase Storage** (`tracks/...`) с отображением реального прогресса в процентах (0-100%).
     - Сохранение метаданных (`title`, `artist`, `duration`, `audioUrl`, `storagePath`, `createdAt`) в Firestore.
     - Список загруженных треков с возможностью удаления файлов из хранилища и базы.

3. **Автоматическое назначение первого Администратора**:
   - Самый первый зарегистрированный в базе пользователь автоматически получает статус администратора (`isAdmin: true`).
   - Все последующие зарегистрированные пользователи получают обычные права игрока (`isAdmin: false`).

4. **Клиентское шифрование (Web Crypto API)**:
   - **Пароли:** хэшируются алгоритмом `SHA-256` с динамической солью строго в браузере до отправки в Firestore. Открытый пароль никогда не попадает в сеть или в базу данных.
   - **Игровая статистика:** результаты каждого раунда шифруются симметричным шифром **AES-GCM (256-bit)** с уникальным 12-байтным вектором инициализации (IV). В базу улетает только зашифрованный Base64 шифротекст.

5. **Воспроизведение без микро-задержек (Web Audio API)**:
   - Никаких тегов `<audio>` для игрового процесса.
   - Аудиопоток скачивается из Firebase Storage и полностью декодируется в память устройства через `AudioContext.decodeAudioData()`.
   - Воспроизведение через `AudioBufferSourceNode` с аппаратной привязкой к `audioCtx.currentTime`.
   - **Pulse Engine:** оригинальный алгоритм анализирует спектральную энергию (flux) раскодированного аудио и процедурно расставляет короткие тапы и длинные hold-ноты под ритм мелодии с детерминированным сидом.

6. **100% сохранение оригинального геймплея и дизайна**:
   - 4 неоновые дорожки: управление клавишами **[S]**, **[D]**, **[J]**, **[K]** или касаниями на мобильных устройствах (Pointer Events с мультитачем).
   - Все цветовые палитры комбо: `STEEL` (0-14), `ELECTRIC` (15-29), `GOLD` (30-49), `COSMIC` (50-74), `LEGENDARY` (75+, с динамической аурой и легендарной рамкой).
   - Длинные hold-ноты с тиками очков и искрами при удержании.
   - Динамический эквалайзер на линии удара, запитанный от частотного анализатора `AnalyserNode`.
   - Звездная система (★, ★★, ★★★) и всплывающие судейские оценки (ІДЕАЛЬНО, ДОБРЕ, ПРОМАХ).

## 🚀 Быстрый запуск

Для запуска достаточно любого локального статического веб-сервера:

### Через Python:
```bash
python3 -m http.server 3000
```
После запуска откройте в браузере: **http://localhost:3000**

## ⚙️ Настройки Firebase (Firestore & Storage Rules)

Убедитесь, что в Firebase Console открыты правила чтения и записи:

### Firestore Rules:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

### Storage Rules:
```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /tracks/{allPaths=**} {
      allow read, write: if true;
    }
  }
}
```
